# Love Notes

A [Chickadee Bandit](https://chickadeebandit.com/app-library/love-notes) app.

A private inbox for leaving short notes, compliments, or reminders for your partner.

## Features

- Short notes, compliments, reminders.
- A private inbox per partner.
- Reciprocal partner setup.
- Adults only.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-love-notes/releases/latest/download/bundle.json
```
